# Blender-Script-Suite
Scripts I have developed to help with various problems in Blender that don't have good solutions already built into the program

## Brief descriptions of the listed scripts
Find the script that you need for your problem easier

### vertex_smooth
- snap a messy vertex selection onto the smooth shape that best fits it.
- least-squares smooth curve (polynomial), best-fit circle (arc), or a polynomial height field over the patch's own plane
- Built in logic to help you choose which is most applicable - or experiment
- Fine-tune any of the above options
